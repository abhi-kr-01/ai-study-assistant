Phase 1 : Document Loading , Text Extraction and chunking
Document loader	Reads a file and extracts its contents
Text extraction	Converts PDF pages or text files into machine-readable text
Document	LangChain's data structure for text plus metadata
Metadata	Information such as filename, page number and document ID
Chunking	Splitting long text into smaller pieces
Chunk size	The target size of each piece
Chunk overlap	Text shared between consecutive chunks
Source attribution	Preserving where a piece of text originated

langchain-community : provides the PyPDFLoader integration. -- for pdf upload 
pypdf: extracts text from PDF files.
langchain-text-splitters: provides reusable text chunking algorithms.
